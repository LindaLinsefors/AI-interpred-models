## The second-argmax network
- $h_t = \mathrm{ReLU}(W_{ih} x_t + W_{hh} h_{t-1})$, $h_{-1} = 0$, $\ell = W_{out} h_9$. There are no biases, and the input has length 10. Parameters: $16 + 256 + 160 = 432$.
- Weights: `reverse-engineered-networks/1-algzoo-second-argmax-432/code/m16_10.pth` (also `m16_10_weights.npz`). `code/full_account.py` defines the colleague's 13-mode basis (`ANALYSIS`, `SYNTHESIS`, `ORDINARY`, `PULSE_UNITS`).
- Unit groups (from the colleague's paper): comparators 1, 6, 7, 8 | pulses 4, 5, 9 | wave units 0, 2, 3, 10–15. The shared unit order and colours are in `1-algzoo-second-argmax-432/hide/plot_weights.py` (`GROUPS`, `ORDER`, `UNIT_COLOR`).
- Input distributions: the colleague's analysis uses iid $\mathcal{N}(0,1)$. The original was trained on iid $\mathrm{Unif}(-1,1)$. Being bias-free, the network is scale-equivariant.
- Original accuracy: 93.78% on uniform inputs and 95.31% on Gaussian inputs ($2^{20}$-sample test sets).

## Findings so far
- Replica training (see `replica/README.md`): with batch size 64 the original is roughly a top-10% seed. Best of 32 seeds gives `replica_nobias` at 95.6% uniform. Adding biases trains worse (median about 75% vs 90.5%), probably because biases break positive homogeneity.
- Linear probes on $h_t$, separate per $t$ (`archived-probed/linear-probes-for-every-t/`; Gaussian inputs, 200k train / 50k test, one probe per target and $t$ plus one pooled over $t$). Targets use the window $x_0..x_t$ ("incl") or $x_0..x_{t-1}$ ("excl"). Steps since the $k$-th max is $t - p_k$, counted from the current step.
  - Values (affine least squares, R²): max 0.97–1.00; 2nd max 0.81–0.95; 3rd max 0.45–0.88.
  - Steps since (multinomial logistic regression, C = 10, accuracy): max 0.97–1.00; 2nd max about 0.95 (incl) and 0.78 (excl) at late $t$; 3rd max falls to about 0.24, against a 0.10 majority baseline at $t = 9$.
  - The user asked for ages to be probed only with classifiers, and the regression results for ages were removed. When they were regressed, R² was only 0.06–0.74, because the age is held as a clock phase rather than linearly.
  - Independent agents checked the targets (exact match) and spot-checked the R² and accuracy values (within 0.02). Weaker regularisation adds 0.01–0.03 to a few classifier cells.

- Impulse $x = (1,0,\dots,0)$ (`rotate/`): $h_0$ is unit 4 alone, then unit 5 at $t = 1$. From $t = 2$ the state rotates about 41° per step. With the fit on $t = 2..9$, PC0 + PC1 hold 99.8% of the variance, so the rotation is planar. A second input 2 at step $p$ leaves $h_p$ on the impulse orbit; the state jumps at $p + 1$ onto a larger, restarted orbit. The plane (PC0, PC1 of $h_2..h_9$, directions $V$, mean $m$) misses the origin: the perpendicular from the origin is $n = (I - V^\top V) m$ with $|n| = 34.99$, against an in-plane radius of 22.1 and an off-plane rms of 0.91. Vectors orthogonal to the plane form a 14-dim space, so $n$ is unique only as the one in the 3-dim span of the plane and the origin.

## Gotchas
- Verification lessons from the mechanistic report: (1) $R^2$ of activations, and uncentred $R^2$ of quantities that scale with $|x|$, are lenient (a model with no dynamics reaches 0.82–0.997): use functional tests (accuracy after an ablation) before calling a subsystem closed. (2) Pooled statistics hid the real variables several times (wipe step, age of the old runner-up, step of the new max, pairs that include the input before last): split by configuration before interpreting a trend. (3) A forcing test that replaces a value by an earlier, larger one tests "low", not "zero": test a ReLU by letting the unit go negative. (4) Only 10% of states are in the exact resting gate pattern, so statements derived from the resting map are linearisations.
- Workflow subagents cannot write `.md` report files (the harness refuses): have them return text and dump it from the workflow journal (`mechanistic-report/hide/dump_*_results.py`). Long `python -c` one-liners or heredocs with LaTeX/regex can be refused or mis-parsed by Bash: write a script file instead.
- Start Claude Code from this workspace root. Auto-memory is stored per launch folder, so a session launched from a subfolder starts with an empty memory. This CLAUDE.md is still found from subfolders.
