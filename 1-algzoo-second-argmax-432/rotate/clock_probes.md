# Clock-phase probes

Affine least-squares probes on $h_t$ (all 16 units), one per target shared by all $t$. Targets $\cos(\omega a)$, $\sin(\omega a)$ with $a = t - p_k$ (window $x_0..x_t$), states with $a = 0$ excluded. iid $\mathcal N(0,1)$ inputs, 200k train / 50k test sequences. Angle error: median $|\operatorname{arg}(\hat c + i\hat s) - \omega a|$. Script: `hide/rotate/clock_probes.py`.

The short-lived clock (42.98°) has no rows: for $a \le 9$ its targets are within $9 \times 0.23° \approx 2°$ of the main clock's (42.75°), so its probes and scores are the same. The alternating mode (180°) has only a cos probe: $\cos(180° a) = (-1)^a$ and $\sin(180° a) = 0$. Its angle error is 0° when the sign of the prediction is right and 180° when it is wrong.

**How good each probe is:** $R^2$ is the held-out $R^2$ of the cos and sin predictions together, $1 - \sum |\hat y - y|^2 / \sum |y - \bar y|^2$ with $y = e^{i \omega a}$ (1 = perfect, 0 = no better than a constant). It is repeated in the per-unit tables below.

## Which units each probe uses

The cos and sin probes of a row are combined into one complex weight per unit, $z_u = (w^{\cos}_u + i\, w^{\sin}_u)\, \sigma_u$, with $\sigma_u$ the std of $h_u$ over the training states. The prediction is then $\hat c + i \hat s = \sum_u z_u (h_u - \mu_u)/\sigma_u + \text{const}$, so when $h_u$ is one std above its mean it adds $|z_u|$ in the direction $\arg z_u$ to the predicted $e^{i\omega a}$. **Colour:** amplitude $|z_u|$ relative to the largest in its row (darkest = the row's value in the max |z| column). **Arrow:** phase $\arg z_u$, the clock phase $\omega a$ the unit votes for (0° points right, 90° up, counter-clockwise like $e^{i\omega a}$ in the $(\cos, \sin)$ plane). Blank: $|z_u| < 0.25 \max_{u'} |z_{u'}|$ in that row. Columns in group order (blue: comparators, orange: pulses, grey: wave units).

## Eigenmodes of $W_{hh}$

Eigendecomposition of $W_{hh}$ restricted to the 13 non-pulse units, $A v_m = \lambda_m v_m$, one row per mode (a complex-conjugate pair is one row). While the pulse units are 0 and no unit is clipped, $h = \sum_m c_m v_m$ and each step multiplies $c_m$ by $\lambda_m$, so a complex mode moves unit $u$ as $2\,\mathrm{Re}(c_m v_{m,u}) = 2\,|c_m|\,|v_{m,u}| \cos(\arg c_m + \arg v_{m,u})$, with $\arg c_m$ advancing by $\omega_m = \arg \lambda_m$ per step.

**Colour:** $|v_{m,u}|$ relative to the largest in its row. **Arrow:** $-\arg v_{m,u}$, the mode phase $\arg c_m$ at which the mode makes unit $u$ largest. **Phase convention:** the overall phase of $v_m$ is arbitrary. It is fixed so that the mode coordinate $c_m = \ell_m^\dagger h$ ($\ell_m$: left eigenvector) has mean phase $\omega_m a_1$, that is $\arg \langle c_m e^{-i \omega_m a_1} \rangle = 0$, over the training states with $a_1 \ge 1$ ($a_1$: steps since the max). So an arrow is the clock phase $\omega_m a_1$ at which the unit peaks, which makes these rows comparable with the "max" rows of the probe table above. **Coherence** $= |\langle c_m e^{-i \omega_m a_1} \rangle| / \langle |c_m| \rangle$: near 1, the mode's phase is locked to $a_1$; where it is low, only the relative directions within the row mean anything (for the modes with $\omega_m = 0$ it only says how consistently $c_m$ keeps one sign). For the real modes the arrow is a sign: right, the unit rises with $c_m$; left, it falls; $c_m$ is positive on average (for the alternating mode, at even $a_1$). Blank: $|v_{m,u}| < 0.25 \max_{u'} |v_{m,u'}|$. –: the pulse units are not part of the 13 × 13 block.
