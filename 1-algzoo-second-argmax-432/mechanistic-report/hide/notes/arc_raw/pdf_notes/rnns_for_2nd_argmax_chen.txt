1 Introduction

The goal of this work is to perform mechanistic interpretation analysis on an algorithmic
task, aiming to develop a heuristic estimate through this analysis. Ideally, we hope to use
mechanistic analysis to extract the high-level algorithm and employ heuristic arguments
to address any remaining fuzziness, providing an estimate of the model’s accuracy.

    In this note, we discuss progress towards this goal for the task of finding the index
of the second largest number in a sequence, which we refer to as the ”2nd argmax task”
throughout. We train vanilla one-hidden-layer recurrent neural networks (RNNs) for this
task. Intuitively, the concept of max or argmax should emerge from these networks, which
is empirically confirmed. Hence, we begin by training linear RNNs on the argmax task as
a step towards the 2nd argmax task.

2 Problem setup

Given a sequence of real numbers x = (x1, x2, ..., xd), where each entry is sampled i.i.d.
from the uniform distribution Unif[−1, 1], we train simple RNNs to solve the d-way clas-
sification task of predicting the maximum entry (argmax) and the second-largest entry
(2nd argmax) in the sequence. We consider the simple class of one-hidden-layer RNNs.
More specifically, the RNN architecture is given by the following equations:

                                          h0 = 0
                                       ht+1 = ReLU(Whhht + xtwih)

                                           y = Wohhd+1,
where ht ∈ Rm is the hidden state at time t, initialized with h0 = 0. wih ∈ Rm, Whh ∈
Rm×m are the input weights and recurrent weights for the hidden layer, respectively. The
ReLU activation function is applied element-wise. The output y ∈ Rd represents the logits

    We would like to make the following observations of the setup and the model.

Generalization of the input range The RNN architecture with ReLU activations
and without biases exhibits a generalization property with respect to the input range.
Since ReLUs are positive homogeneous functions, i.e., ReLU(αx) = αReLU(x) for any
α > 0, the network’s computations are equivariant to positive scaling of the input se-
quence. Specifically, if we scale the input sequence (x1, x2, ..., xd) by any positive constant
α, the output will scale by α as well. This implies that the network’s behavior general-
izes beyond the [−1, 1] input range, maintaining the same accuracy across all symmetric
uniform distributions.

Equivariance and invariance The RNN exhibits an equivariance property with re-
spect to the positive scaling of the hidden state representations. Specifically, let D ∈ Rm×m
be a full-rank positive diagonal matrix, and define the scaled hidden state ht′ = Dht.
Then, there exists an equivalent RNN with modified weights. Let Wh′ h = DWhhD−1,
wi′h = Dwih, Wo′h = WohD−1 and ht′ be the transformed weights. It can be shown that:

                                                    ht′ ≡ Dht

and
                                y′(x1, x2, ..., xd) = Wo′hh′d+1 ≡ Wohhd+1.

The model also exhibits invariance with respect to the output matrix Woh. Note that
W ′oh = W oh + 1uT has exactly the same model output, loss, and accuracy as Woh due
to the shifting-invariance of the softmax function. With strong weight decay, we should
expect each column of Woh to sum to 0, implying the average of all output directions is
the 0 vector. However, our main RNN model for the 2nd argmax task was not trained
with very strong weight decay for generalization concerns.

Accuracy of intermediate logits Since the network does not have bias terms, the
model output after receiving the input sequence (0, 0, ..., 0, x1, x2, ..., xt) is identical to
receiving (x1, x2, ..., xt) at time t. This implies the intermediate logit values should reflect
the running classification result. For example, for the argmax task, we should expect the
intermediate logits to reflect the current max index, even though the training cross-entropy
loss does not explicitly include the intermediate logits. A similar rationale holds for the
2nd argmax task as well. However, the intermediate accuracies may not be monotonically
decreasing since we don’t explicitly train for the accuracy when the inputs start with 0s

Spurious correlation and backdoors Note that with high probability, the max and
the 2nd max values are positive. Therefore, the neural networks are not incentivized
to perform well on purely negative sequences, an effect further enhanced by the ReLU

3 Linear RNN for Argmax

In the simpler case of a linear RNN, we remove the nonlinearity from the architecture
and focus on the scenario where m ≥ d. The hidden state updates become ht+1 =
Whhht + xtwih. Without the nonlinearity, the hidden state dynamics and the output
logits are linear functions of the input sequence x = (x1, x2, ..., xd). We can write the
overall input-output mapping as a linear function y = Ax, where A ∈ Rd×d is a matrix
that encapsulates the linear transformation performed by the RNN:

                              A = Woh Whdh−1wih Whdh−2wih · · · wih .

    The matrix A represents the linear mapping from the input sequence x to the output
logits y, which is obtained by multiplying the input weight vector wih with successive
powers of the recurrent weight matrix Whh, and then applying the output weight matrix
Woh.

    The extracted matrix A is also the covariance between the logits and input (up to
scaling). Note that, in order for the argmax of the output logits y to always coincide with
the argmax of the input sequence x, the matrix A must satisfy :

                                                 A = cI + 1uT

where c is a scalar, I is the d×d identity matrix, 1 is the d-dimensional vector of ones, and
u is a d-dimensional vector. This representation ensures that the linear transformation
performed by A preserves the ordering of the input elements while allowing for a constant
shift and scaling.

    The specific values of the RNN weights Whh and wih are not crucial, as long as the
concatenated matrix [Whdh−1wih Whdh−2wih ... wih] has full rank. In fact, we can simply set
Woh = [Whdh−1wih ... wih]† to obtain A = I directly. For instance, we can even take Whh and
wih as random, although the condition number of the concatenated matrix exponentially
blows up and the learning dynamics do not favor these solutions. Empirically, Whh tends
to be a cyclical shift in the directions specified by the output matrix Woh.

3.1 A naive heuristic estimate

Based on the previous observation regarding the extracted linear transformation A, we
can obtain a simple heuristic estimate of the classification accuracy:

   1. For a given A extracted from the trained network, we find the best approximation
       of the form (D + 1uT ) in the Frobenius norm, where D is a diagonal matrix.

                                                          3
   2. We use P[arg max Dx = arg max x] as the accuracy estimate. This can be analyti-
       cally computed for the uniform distribution.

    The diagonal matrix D represents how well the linear RNN decodes the values of each
direction/index. This procedure doesn’t account for the approximation error of the 1uT
(applying the presumption of independence) and thus tends to overestimate the accuracy.

    Despite its simplicity, this heuristic estimate can be used for detecting some backdoors.
For instance, suppose the linear RNN was trained to classify arg max(x1, ..., −xp, ..., xd)
for some specific poisoned index p. The resulting RNN can have a decent accuracy up
to 1 − 1/d, but it will have a negative Dpp, which can be detected based on the estimate
procedure.

4 Nonlinear RNN for Argmax

Since the argmax task can be perfectly solved by a linear RNN with m neurons, the
benefits of non-linear networks mainly lie in representation efficiency (i.e., fewer neurons
are required). To perfectly solve the task, the network needs to learn a (d − 1)-dimensional
vector representing the differences among the input sequence, which requires at least d − 1
neurons for linear networks.

    Let’s consider a few scenarios that may require different explanations:

   1. A trained linear RNN with the same number of neurons as the input degree of
       freedom, i.e., m = d − 1.

   2. We first obtain a linear RNN by randomly sampling the weights Whh and wih. Then
       we take Woh as the inverse of the aforementioned concatenated matrix yielding a
       perfect linear RNN. Next, we add ReLU to this network, but it can still obtain a
       decent accuracy. 1

   3. A trained RNN with m = d − 1 neurons.

   4. A trained RNN with m ≤ d − 2 neurons.

    The first is well understood. For the second, we need to explain why ReLUs are benign
distortions. The third and fourth likely require different explanatory mechanisms. Our
goal was full mechanistic interpretations for all cases, but this quickly became challenging
when nonlinearities played a key role. As an example, if the network simply approximates
the identity, mechanistically explaining how may be less important. Instead, treating it
as a black box and arguing the input-output mapping could suffice. Ideally, a generic
heuristic estimator (e.g., bin propagation 2) could justify such components. However, we
avoided involving these generic procedures and focused on attempts that are potentially
parochial. We do not expect covariance propagation to work well in this setting due to
several layers of nonlinearity.

It is straightforward to construct a ReLU RNN with 2d neurons that can implement the
identity function and thus achieve perfect accuracy. We can set the input weight vector
wih to contain a 1 and −1 with zeros elsewhere so that we can extract the latest input xt
as ReLU(xt) − ReLU(−xt). The remaining 2d − 2 neurons are used for shifting and storing
these values. We can also reduce the total number of neurons to d by only computing and
storing ReLU(xt), which incurs an exponentially small error rate. Indeed, there are other
constructions of computing the argmax without preserving the total order of the sequence.
These could serve as a starting point for gaining intuition about the trained networks.

5 Nonlinear RNN for 2nd Argmax

For the 2nd argmax task, nonlinearity and more neurons are required. In this section,
we focus on our analysis of a 16-neuron RNN that achieves 94% accuracy on the uniform
distribution for sequence length d = 10. We sketch some findings of the trained network
and a hand-coded network inspired by these findings. Visualizations and details can be
found in the notebook.

5.1 Mechanistic Findings

We summarize a few more definitive findings of the network, which we will use as hints to
construct an almost-perfect RNN.

                                    5
   1. We have several major input neurons: N1, N4, N6, N7, N8. The weight for N4 is
       positive, while the others are negative.

   2. N2 approximately implements the running max value maxt, N4 approximately im-
       plements ReLU(xt − maxt), and N7 approximately implements ReLU(maxt −xt).

   3. N8 approximately implements ReLU(2ndmaxt − xt) in earlier time steps.

   4. When calculating the logits at each time t, projecting out the negative input neurons
       (N1, N6, N7, N8) gives an argmax/max sub-circuit that accurately finds the max
       index.

   5. At a high level, new values enter through the last logit (m-th), and the previous val-
       ues (inexactly) shift to earlier logits. For each iteration t, if xt > maxt (running max
       value), the old max logit gets a boost. Note that this restates that the intermediate
       logits have good accuracies for the running 2nd argmax.

5.2 The handcoded RNN

The high-level idea is to maintain a set of features, mk and sk, for representing the scores
of each index as the max and the 2nd max index, respectively. They correspond to the
intermediate logit values and the projected logit values in the trained network. In other
words, arg max mk is the max index, and arg max sk is the 2nd max index at each time
step.

    When the new input xt is larger than the running max, i.e., xt > maxt, we need to
update the s value for the current argmax logit. Mimicking the trained network can be
achieved by shifting the m values to the s values. We provide two ways of implementing
this shift in the code: the exact shifting and the approximate shifting. The exact shifting
is conceptually easier to understand, while the approximate shifting uses ReLUs to imple-
ment a step function. The approximate shifting version can be exactly implemented by a
ReLU RNN.

    A simple choice for mk is xk. The choice of s9(xt) is inspired by the trained RNN since
the sum of N4 and N7 gives | maxt −xt|, which is reflected by the weights of the last logit.
Note that there is flexibility in the design of s and m; we provide a few other options
below.

Error analysis Here, we provide an error analysis of the exact shifting version of the
distilled algorithm. The approximate shifting version can be analyzed similarly. This
algorithm always computes the argmax instead of the 2nd argmax when the entire sequence
is negative. When exactly one entry of x is positive (say the k-th), then sk = −xk, which
is correct as long as the largest negative number is larger than −xk. This has a probability
of 0.9. If it is the last entry, then it is correct as long as the largest negative number is
larger than −xk. If it is not the last entry, the update sk ← mk does not affect the result
because they are the same, reducing to the same case as above. When there are two
positive entries, correctness is guaranteed whether the larger one appears earlier or later.
Therefore, this algorithm should have accuracy 1 − (2−10 + 0.1 × 10 × 2−10) ≈ 0.998, which
matches the empirical accuracy.

Discrepencies Overall, the constructed net and the trained net share similar qualita-
tive patterns. N2, N4 and N7 of the trained net have their exact counterparts in the
constructed net. Both nets have a max/argmax sub-circuit. However, there are some
major discrepancies:

    • The constructed 21-neuron net has an accuracy 99%. In comparison, the trained
       16-neuron RNN has an accuracy 94% and empirically we found it hard to train a
       21-neuron RNN with 95%+ accuracy.

    • Both the constructed and the trained net have 1 major positive entry in the input
       weight vector wih. However, the constructed net has 10 negative entries, designated

5.3 Heuristic Estimator

In our attempt, we were primarily focused on complete mechanistic interpretations, which
was hindered by understanding the m (max sub-circuit) and (s − m) feature implementa-
tions. We shifted our efforts to analyzing RNNs for argmax tasks but did not uncover an
explanation for nonlinearity’s benefits. An unexplored direction is pursuing a higher-level
mechanistic view while leveraging generic end-to-end techniques like bin propagation.

    Prior work on end-to-end heuristic estimators includes extracting a deterministic finite-
state automaton (DFA) from the RNN. One approach to state space partitioning is to
divide each dimension into several intervals. Another approach, aiming to avoid dimen-
sionality issues, is to fit an unsupervised classifier such as k-means to a large sample set
of reachable network states. 3
