1 Reduction to Smaller Network

The symmetries we’ve noticed of the argmedian and argoutlier models (of se-
quence length 3 and width 4) are equivalent to the equations

                         whh = U T wh′ hU

                         wih = U T wi′h
                         who = wh′ oV

where U =  1  0   0  −1  ,V =  1  0          0  1  and wh′ h, wi′h, wh′ o are 2x2,
           0  1  −1   0        0  1          1  0

2x1, 3x2 matrices respectively. Notice that

                         U ReLU U T v = v
                         V ReLU U T v = |v|

where by |v| I mean coordinate-wise absolute value rather than norm.
Therefore the function defined by the RNN is

whoReLU (wihx2 + whhReLU (wihx1 + whhReLU (wihx0)))

             = wh′ oV ReLU U T wi′hx2 + U T wh′ hU ReLU U T wi′hx1 + U T wh′ hU ReLU U T wi′hx0
             = wh′ o| (wi′hx2 + wh′ h (wi′hx1 + wh′ h (wi′hx0))) |

    The linear function inside the absolute value is almost generic in the sense
that there is only a codimension > 0 space of linear functions R3 → R2 that
are not of this form. So, RNNs of this size with the symmetries above are
generically equivalent to a (3,2,3) neural network with activation function given
by absolute value.

2.1 Quadrants for the Hidden Layers

First let’s look at the pre-activations for the hidden neurons based on their signs.

2.1.1 Positive Quadrant

In the quadrant where the pre-activation of both hidden neurons are positive,
we have the following:

                                   x0 + λx1 − (1 + λ)x2 > 0,
                                   λx0 + x1 − (1 + λ)x2 > 0.

This implies in particular that x2 < x. In fact it implies something slightly
stronger, that

                                                λ−1
                                 x2 < x − 3(1 + λ) |x0 − x1|.
In fact it is equivalent to this statement. Notice that with our specific values,
the coefficient of |x0 − x1| is approximately 0.06.
